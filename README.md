# ⚔️ Wiki Duel Bot (Гонка по Википедии)

Телеграм-бот для проведения дуэлей и одиночной игры в «Гонку по Википедии» (The Wiki Game).

## 🎮 Правила игры
1. В начале раунда выбираются две случайные статьи: **Старт** и **Цель** (Финиш).
2. Игроки начинают со стартовой статьи и должны добраться до целевой, переходя **исключительно по ссылкам внутри статей**.
3. Побеждает тот игрок, который первым перейдет на целевую статью.

## 📁 Структура проекта
```
wiki_duel_bot/
├── .env                  # Токен бота и настройки окружения
├── requirements.txt      # Зависимости проекта
├── config.py             # Загрузка переменных конфигурации
├── wiki_service.py       # Взаимодействие с Wikipedia API и валидация переходов
├── database.py           # SQLite база данных (пользователи, статистика, матчи)
├── states.py             # Состояния FSM (aiogram)
└── main.py               # Главный файл запуска бота
```

## 🚀 Быстрый запуск

### 1. Установите Python (если еще не установлен)
В PowerShell:
```powershell
winget install Python.Python.3.12
```

### 2. Создайте и активируйте виртуальное окружение
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 3. Установите зависимости
```powershell
pip install -r requirements.txt
```

### 4. Настройте токен бота
Откройте файл `.env` и вставьте токен вашего бота от [@BotFather](https://t.me/BotFather):
```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ_example
```

### 5. Запустите бота
```powershell
python main.py
```
